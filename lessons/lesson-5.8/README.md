# Урок 5.8. Исследовательский субагент

RepoPilot поручает ограниченное исследование отдельному read-only субагенту. Родитель получает краткие findings с источниками, проверяет их происхождение и перечитывает нужные строки в собственном запуске.

## Что вы освоите

- Запускать исследование с отдельным контекстом и разрешёнными инструментами чтения.
- Учитывать общий бюджет родителя и субагента и обрабатывать отмену.
- Проверять происхождение findings и связывать их с родительским чтением тех же версий.

## Домашнее задание

Добавьте план недостающих родительских чтений: объединяйте пересекающиеся цитаты, вычитайте уже прочитанные строки и разбивайте остаток под бюджет. Для устаревших и конфликтующих версий возвращайте явный результат.

Условия и критерии приёмки — в [README задания](homework/README.md). Результат оформите в [SUBMISSION.md](homework/SUBMISSION.md).

## Проверка

Оба блока выполняйте отдельно, начиная из папки `lesson-5.8`. Подготовка среды описана в лекции.

Базовые Java- и UI-проверки рабочего примера:

```bash
cd lecture
./mvnw test
npm ci
npm test
```

Базовые и приёмочные проверки домашнего задания:

```bash
cd homework
./mvnw test
./mvnw -Phomework verify
npm ci
npm test
```

Приёмочные тесты описывают новую функцию и начнут проходить после её реализации. Запуск приложения и дополнительные интеграционные проверки описаны в [полной лекции](lecture/README.md).
