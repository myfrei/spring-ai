Отдельный исследователь получает чистый контекст и три read-only tools. Родитель и ребёнок делят бюджет и флаг кооперативной отмены. Короткий child report проверяется по реальным child receipts, а родитель обязан перечитать принятые цитаты в собственном run. Skills, план, compaction, ручные разрешения и verification state сохраняются в прежней композиции.

В homework добавляется отдельный ограниченный план повторного чтения с объединением диапазонов и учётом уже прочитанного. Готовую реализацию подзапуска повторять не требуется.
