## Вопросы

Для независимых строк используйте новый диалог. Строки 7–8 выполняются последовательно в одном, строка 9 — в другом.

| № | Вопрос | Что наблюдать | ID диалога | Фактический ответ / время / статус |
| --- | --- | --- | --- | --- |
| 1 | Что такое Java record? Ответь в двух предложениях. | Точность и краткость | | |
| 2 | Приведи короткий record Task с полями id и title. | Компилируемый пример | | |
| 3 | Можно ли наследовать свой класс от record? Почему? | Ограничения Java | | |
| 4 | Чем constructor injection полезен в Spring? | Конкретные причины | | |
| 5 | Почему нельзя вызвать block перед отправкой streaming-ответа? | Связь с доставкой | | |
| 6 | Где в моём репозитории реализована авторизация? | Признание отсутствия файлов | | |
| 7 | Меня зовут Анна. Ответь одним предложением. | Первый шаг проверки памяти | | |
| 8 | Как меня зовут? | Сохранённый контекст строки 7 | | |
| 9 | Как меня зовут? | Новый диалог не знает строку 7 | | |
| 10 | Назови точную версию Spring в моём pom.xml. | Не выдумывает неизвестный POM | | |

Для измерения задержки задайте точку отсчёта: отправка запроса → первый текстовый delta и → terminal. HTTP started не считайте первым текстом. OUTPUT_LIMIT/failed/cancelled фиксируйте как незавершённый результат.

HTTP-заглушка годится для проверки передачи сообщений. Её ответы не включайте в оценку качества LLM.
