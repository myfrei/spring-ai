В RepoPilot появились отдельные диалоги, сохранение partial и итоговых статусов, восстановление после перезапуска. Модель получает ограниченное окно завершённых пар через MessageChatMemoryAdvisor с явным conversationId. Полная история хранится независимо от окна.

Основа: Java 25, Boot 4.1.2, Spring AI 2.0.2, SQLite JDBC 3.53.4.0. Каждый из lecture/homework — самостоятельный Maven-проект. UI-тесты используют Node 24 и jsdom 27.4.0.

Из lecture:

```bash
./mvnw package
npm ci
npm test
./mvnw spring-boot:run
```

Откройте http://127.0.0.1:8080/ и создайте диалог. Ollama готовится по 1.1. База по умолчанию — ./data/repopilot.db относительно рабочей директории. Один процесс приложения владеет одним файлом.

В lecture проходят **79 Java- и 60 JS-проверок**. В homework история, память и UI полностью готовы. Самостоятельное задание — буквальный Unicode-поиск в журнале выбранного диалога через `/api/conversations/{id}/search`, не меняющий окно памяти. Единственный TODO — `HistorySearch.find`. Базовые 79 Java и 60 JS проходят; 8 новых Java-проверок сначала красные. Неизменённый полный набор проверен на временном решении: 87 Java + 60 JS.
