# Урок 5.9. Web и консольный REPL

RepoPilot получает два интерфейса над одним координатором: страницу агента и Java-консоль. Задачи выполняются в фоне, а клиент наблюдает события, переподключается к сессии и передаёт явные команды человека.

## Что вы освоите

- Разделять запуск задачи, чтение состояния и наблюдение за событиями.
- Обрабатывать повторный запрос, восстановление ленты и кооперативную отмену.
- Использовать общую модель плана и ручных разрешений в Web и REPL.

## Домашнее задание

Добавьте inbox по нескольким сессиям: показывайте ожидающие разрешения и непросмотренные остановки по приоритету. Отметка «Просмотрено» меняет отображение уведомлений. Ожидающее разрешение остаётся видимым до отдельного решения человека.

Условия и критерии приёмки — в [README задания](homework/README.md). Результат оформите в [SUBMISSION.md](homework/SUBMISSION.md).

## Проверка

Оба блока выполняйте отдельно, начиная из папки `lesson-5.9`. Подготовка среды описана в лекции.

Базовые Java- и UI-проверки рабочего примера:

```bash
cd lecture
./mvnw test
npm ci
npm test
```

Базовые и приёмочные проверки домашнего задания:

```bash
cd homework
./mvnw test
./mvnw -Phomework verify
npm ci
npm test
```

Приёмочные тесты описывают новую функцию и начнут проходить после её реализации. Запуск приложения и дополнительные интеграционные проверки описаны в [полной лекции](lecture/README.md).
