# Урок 5.6. Бюджет контекста и compaction

RepoPilot сохраняет полный журнал, но отправляет модели ограниченный рабочий контекст. Вы замените старые завершённые обмены с инструментами компактными метаданными и сохраните текущую задачу, правила, план и последние результаты.

## Что вы освоите

- Учитывать бюджет контекста вместе со схемами tools и резервом ответа.
- Сокращать старые обмены, сохраняя связь вызова инструмента с результатом.
- Различать полный журнал, рабочую проекцию и фактическую статистику модели.

## Домашнее задание

Добавьте возврат к сохранённым результатам readFile по ID вызова. Проверяйте принадлежность запуску и текущую версию файла, возвращая целый JSON в пределах общего UTF-8 бюджета.

Условия и критерии приёмки — в [README задания](homework/README.md). Результат оформите в [SUBMISSION.md](homework/SUBMISSION.md).

## Проверка

Оба блока выполняйте отдельно, начиная из папки `lesson-5.6`. Подготовка среды описана в лекции.

Базовые Java- и UI-проверки рабочего примера:

```bash
cd lecture
./mvnw test
npm ci
npm test
```

Базовые и приёмочные проверки домашнего задания:

```bash
cd homework
./mvnw test
./mvnw -Phomework verify
npm ci
npm test
```

Приёмочные тесты описывают новую функцию и начнут проходить после её реализации. Запуск приложения и дополнительные интеграционные проверки описаны в [полной лекции](lecture/README.md).
