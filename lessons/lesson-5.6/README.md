Один и тот же runtime сохраняет полный raw journal и строит ограниченную проекцию для очередного вызова модели. Старые завершённые tool exchanges можно заменить детерминированными метаданными; вопросы человека, текстовые ответы, текущие правила, план, Skills и последний результат сохраняются. Непомещающийся обязательный контекст приводит к явному отказу до вызова LLM.

ДЗ добавляет контролируемое чтение целых сохранённых результатов того же run под общим лимитом. Студент пишет новую policy; готовые projector, loop, HTTP и инструменты повторять не нужно.
