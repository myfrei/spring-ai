# Чек-лист Java review

- Границы входных данных: null, пустое значение, отрицательные числа, переполнение.
- Состояние до и после операции; отсутствие частичного изменения при ошибке.
- Конкурентный доступ и неизменяемые возвращаемые коллекции.
- Регрессионный тест для конкретного дефекта; факт исполнения теста указывается отдельно.
- Замечание без прочитанного кода остаётся гипотезой.
