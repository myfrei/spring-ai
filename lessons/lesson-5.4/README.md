# Урок 5.4. Skills: каталог и активация

RepoPilot использует проектные Skills — процедуры для конкретных задач. Сначала модель видит краткий каталог, затем получает инструкции выбранного навыка и необходимые references, связанные с его версией.

## Что вы освоите

- Загружать каталог Skills и проверять метаданные SKILL.md.
- Разделять знакомство с каталогом, активацию и чтение дополнительных ресурсов.
- Отслеживать версию инструкций и сохранять действующие ограничения tools и разрешений.

## Домашнее задание

Добавьте подбор набора Skills: проверьте запрошенные версии, устраните повторы и выберите подходящие навыки в пределах общего бюджета байтов. Предпросмотр показывает причины исключения каждого элемента.

Условия и критерии приёмки — в [README задания](homework/README.md). Результат оформите в [SUBMISSION.md](homework/SUBMISSION.md).

## Проверка

Оба блока выполняйте отдельно, начиная из папки `lesson-5.4`. Подготовка среды описана в лекции.

Базовые Java- и UI-проверки рабочего примера:

```bash
cd lecture
./mvnw test
npm ci
npm test
```

Базовые и приёмочные проверки домашнего задания:

```bash
cd homework
./mvnw test
./mvnw -Phomework verify
npm ci
npm test
```

Приёмочные тесты описывают новую функцию и начнут проходить после её реализации. Запуск приложения и дополнительные интеграционные проверки описаны в [полной лекции](lecture/README.md).
