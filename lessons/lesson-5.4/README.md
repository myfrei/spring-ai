RepoPilot показывает модели краткий каталог процедур. Полный SKILL.md поступает в контекст после явного выбора или activateSkill; references читаются только активированной версии. Версия включает инструкции и ресурсы. Skill не расширяет режим, набор tools или разрешение на запись: прежний controlled loop и ручное решение человека сохраняются.

В lecture находятся два проектных Skills и рабочий пример, в homework — та же готовая база плюс новое требование выбора набора запрошенных версий под бюджет. Приёмочные тесты ДЗ проверяют самостоятельную policy; загрузчик, HTTP и runtime переписывать не требуется.
