## 4. Границы и ошибки

| Сценарий | Как воспроизведён | Ожидаемая граница | Наблюдение |
| --- | --- | --- | --- |
| Модель отвечает текстом без getTask | | Нет успешного MODEL без обязательных данных | |
| getTask другого ID | | Не засчитать получение нужной задачи | |
| Неверный raw JSON / неизвестные поля / неверный taskId | | Проверка до domain callback, безопасная ошибка | |
| Параллельные/повторные tool calls | | Считать attempts, соблюдать лимиты | |
| Превышен лимит model calls | | Не запускать следующий inference | |
| Переполнен полный per-round prompt | | Отказ до следующего model call | |
| Provider unfinished / unavailable | | Честный неуспех, без выдуманного подтверждения | |
| Digest поменялся после ошибки | | Не принять несовместимый результат | |

Часть сценариев проверяется fixtures. Не утверждайте, что вручную воспроизвели их настоящими весами, если выполнялись только автоматические проверки.
