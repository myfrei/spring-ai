# ADR-0001: локальный runtime TaskShelf

Статус: принято. Версия учебного решения: 1.

## Контекст

Контекст: студент должен запускать небольшой сервис без отдельного сервера БД.
## Решение

Решение: локальный профиль использует SQLite, файл ./data/tasks.db относительно рабочей директории.
Один процесс TaskShelf владеет одним файлом. Запуск двух копий на одном файле не поддерживается.

## Обоснование

Причина: простая настройка среды и воспроизводимые упражнения. PostgreSQL рассматривается отдельно,
когда нужны конкурентные writers и серверное развёртывание.

Следствие: при смене рабочей директории можно случайно открыть другой файл данных.
Перед диагностикой «пропали задачи» проверяется фактический путь БД.
