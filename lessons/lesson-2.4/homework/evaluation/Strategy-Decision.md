## Правила ручной оценки

Ответ: 0 — неверный/выдуманный; 1 — частичный без достаточных оговорок; 2 — верный и достаточный. Для неизвестного факта 2 означает обоснованное сообщение о нехватке данных, а не догадку.

Источники: 0 — выдуманная/неподтверждающая ссылка; 1 — частично подтверждают; 2 — подтверждают нужные утверждения либо обоснованно не приводятся при отказе. CHAT может правильно назвать факт из других знаний, но не имеет источника проекта. Наличие Document в prompt не доказывает верность цитаты.

refusalCorrect заполняйте отдельно: true/false только после проверки применимости. null означает «не проверено/не применимо».

Для оценки откройте кейс в src/main/resources/evaluation/cases.json, исходные документы и реально переданные sources в отчёте. expectedAnswer и evidenceGroups не передаются модели. Не оценивайте ответ по одному совпавшему слову.
