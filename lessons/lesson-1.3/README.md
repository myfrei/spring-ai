# Урок 1.3. Streaming, отмена и незавершённые ответы

RepoPilot начинает показывать ответ по мере генерации. Добавим потоковый API и научим интерфейс различать готовый ответ, остановленный запрос и обрыв соединения.

## Что вы освоите

- Передадите поток Spring AI в SSE-события `started`, `delta`, `completed` и `failed`.
- Прочитаете POST-поток через `fetch` и соберёте постепенно появляющийся ответ.
- Добавите отмену и повтор запроса, сохранив видимое различие завершения и частичного текста.

## Домашнее задание

Добавьте ограничение длины ответа в новом `/api/chat/limited-stream`. Считайте Unicode code points, сохраняйте допустимый префикс и завершайте поток при превышении квоты с событием незавершённого ответа.

Обычные streaming, UI и отмена уже готовы. Реализуйте оператор `OutputQuota` по [контракту задания](homework/README.md), а наблюдения и результаты запишите в [SUBMISSION.md](homework/SUBMISSION.md).

## Проверка

Нужны JDK 25 и Node.js 24. Каждый блок выполняется независимо из папки `lesson-1.3`.

Лекционный пример:

```bash
cd lecture
./mvnw test
npm ci
npm test
```

Домашнее задание:

```bash
cd homework
./mvnw -Dtest=OutputQuotaAcceptanceTest test
./mvnw test
npm ci
npm test
```

Новые приёмочные тесты должны пройти после реализации квоты. Реальную генерацию, остановку и повтор запроса проверьте по [инструкции лекции](lecture/README.md).
