# Урок 5.1. Собственный агентский цикл

RepoPilot получает задачу, вызывает доступные инструменты и использует их результаты для ответа. Вы создадите на Java собственный цикл выполнения с отдельными Conversation и Run, журналом и понятными причинами остановки.

## Что вы освоите

- Собирать цикл «модель → инструмент → результат → модель» через Spring AI.
- Связывать вызовы инструментов с ответами и сохранять события запуска.
- Ограничивать число шагов и размер контекста на стороне приложения.

## Домашнее задание

Добавьте остановку при отсутствии прогресса: если агент повторяет действия с теми же результатами, новый маршрут завершает запуск до следующего обращения к модели.

Условия и критерии приёмки — в [README задания](homework/README.md). Результат оформите в [SUBMISSION.md](homework/SUBMISSION.md).

## Проверка

Оба блока выполняйте отдельно, начиная из папки `lesson-5.1`. Подготовка среды описана в лекции.

Базовые Java- и UI-проверки рабочего примера:

```bash
cd lecture
./mvnw test
npm ci
npm test
```

Базовые и приёмочные проверки домашнего задания:

```bash
cd homework
./mvnw test
./mvnw -Phomework verify
npm ci
npm test
```

Приёмочные тесты описывают новую функцию и начнут проходить после её реализации. Запуск приложения и дополнительные интеграционные проверки описаны в [полной лекции](lecture/README.md).
