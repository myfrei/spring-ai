# Проверка Java-изменения

1. Уточни цель изменения и прочитай реальные пути через listFiles/searchText/readFile.
2. Посмотри gitStatus и gitDiff, если это Git workspace. Отсутствие Git не означает чистое состояние.
3. Активируй references/review-checklist.md через readSkillReference текущей версии.
4. Прочитай изменённый метод и относящийся к нему тест. Поиск не заменяет чтение.
5. Опиши только проверяемые замечания: путь, строки, причина и сценарий проявления.
6. Если предлагаешь правку, соблюдай режим и proposePatch. Этот Skill не разрешает запись.
7. Не заявляй, что тесты прошли: в этом уроке инструмент запуска тестов отсутствует.
