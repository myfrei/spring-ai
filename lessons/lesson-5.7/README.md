Фиксированный Docker runner проверяет пять условий StockLedger. Разрешение связано с input revision, command и immutable image ID. Агент читает реальный отчёт, предлагает patch, затем новая версия проверяется по новому ручному разрешению. Typed verification state отделяет проверенный исход от завершения плана чтения.

ДЗ добавляет историческую диагностику стабильности, не повторяя исполнение команды или workflow исправления. Host Maven над исследуемым POM не запускается.
