# Урок 5.7. Изолированные проверки результата

RepoPilot получает фактический результат проверки учебного кода в Docker. Каждое исполнение требует решения человека и связано с точной версией входа, командой и образом; после правки вы запускаете новую проверку.

## Что вы освоите

- Выполнять фиксированный контракт StockLedger в ограниченном Docker runner.
- Сохранять exit code, ограниченный вывод и сведения о проверенной версии.
- Различать успешную проверку, ошибку, timeout и устаревший результат.

## Домашнее задание

Добавьте историческое сравнение отчётов одной версии и образа. Находите согласованные и противоречивые исходы, отделяя их от ошибок инфраструктуры и повторных ссылок на один отчёт.

Условия и критерии приёмки — в [README задания](homework/README.md). Результат оформите в [SUBMISSION.md](homework/SUBMISSION.md).

## Проверка

Оба блока выполняйте отдельно, начиная из папки `lesson-5.7`. Подготовка среды описана в лекции.

Базовые Java- и UI-проверки рабочего примера:

```bash
cd lecture
./mvnw test
npm ci
npm test
```

Базовые и приёмочные проверки домашнего задания:

```bash
cd homework
./mvnw test
./mvnw -Phomework verify
npm ci
npm test
```

Приёмочные тесты описывают новую функцию и начнут проходить после её реализации. Запуск приложения и дополнительные интеграционные проверки описаны в [полной лекции](lecture/README.md).
