# TaskShelf — учебный сервис задач

Это вымышленный проект для курса RepoPilot. Документ не описывает рабочий компьютер студента.

TaskShelf хранит задачи команды и предоставляет REST API. Основной язык — Java 25.
Приложение слушает порт 8091. Для локального запуска используется профиль local.
Проверка готовности: GET /actuator/health/readiness. Ожидаемый статус — UP.

Команда запуска из корня учебного сервиса:

```bash
./mvnw spring-boot:run -Dspring-boot.run.profiles=local
```

Владелец модуля задач — команда Atlas. Тестовая задача TS-42 называется «Сохранить порядок событий».
В этом корпусе не описаны авторизация, облачный production и SLA. Если вопрос относится к ним,
нужны дополнительные документы, а не догадка.
