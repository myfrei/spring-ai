# TaskShelf: запуск и диагностика

1. Проверить Java 25 и результат ./mvnw test.
2. Запустить сервис с профилем local на порту 8091.
3. Проверить GET /actuator/health/readiness.

Если readiness не UP, смотреть локальные логи приложения. При ошибке SQLITE_BUSY убедиться,
что другой процесс не использует тот же ./data/tasks.db. Данные не удалять для «быстрого исправления».

Если ошибка появилась после смены директории запуска, сравнить абсолютный путь файла БД.
При обращении в команду Atlas указать профиль, порт, путь тестовой БД и время ошибки.

Пример JSON ответа учебного API: {"id":"TS-42","title":"Сохранить порядок событий"}.
Фигурные скобки в документах — обычный текст, а не переменные шаблона prompt.
