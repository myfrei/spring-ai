Приложение прикладывает весь небольшой корпус TaskShelf в режиме FULL_CONTEXT, показывает его версию и документы, оценивает бюджет и сокращает историю целыми парами. Если обязательный контекст не помещается, модель не вызывается. CHAT служит сравнением без приложенного корпуса.

Java 25, Boot 4.1.2, Spring AI 2.0.2, SQLite JDBC 3.53.4.0. У lecture/homework собственные Maven Wrapper, POM, package.json и lock-файл. Новые внешние зависимости не добавлены.

Из lecture:

```bash
./mvnw package
npm ci
npm test
./mvnw spring-boot:run
```

Откройте http://127.0.0.1:8080/, создайте независимые диалоги для CHAT и FULL_CONTEXT. Ollama готовится по 1.1. Порт 8091 в документах принадлежит вымышленному TaskShelf, а не приложению RepoPilot.

В lecture проходят **102 Java- и 70 JavaScript-проверок**. В homework предоставлена готовая база lecture и добавлено самостоятельное расширение: закрепление важных пар истории. Один новый policy-TODO и пять дополнительных acceptance; исходные регрессии проходят.

Оценка токенов эвристическая. FULL_CONTEXT ещё не подтверждает CAG: кеширование runtime в примере не измерялось. Следующий урок 2.2 — документы, чанки и embeddings.

Домашнее задание переработано: Лекция берёт свежий непрерывный хвост истории. ДЗ добавляет выбор важных старых пар внутри доступного memory snapshot: они должны пережить удаление свежего хвоста по бюджету. Готовая база lecture предоставлена в homework; новые acceptance проверяют новое поведение, а не повторяют упражнения лекции. См. [условия](homework/README.md).
