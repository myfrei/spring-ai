# Урок 2.1. Управление контекстом и подготовка к RAG

RepoPilot получает документацию учебного проекта. Добавим режим FULL_CONTEXT, в котором модель видит корпус целиком, и сравним его с обычным CHAT при ограниченном бюджете контекста.

## Что вы освоите

- Соберёте prompt из инструкций, документов, истории и текущего вопроса.
- Ограничите контекст бюджетом и будете удалять историю целыми парами сообщений.
- Зафиксируете версию корпуса и сравните CHAT с FULL_CONTEXT в одинаковых условиях.

## Домашнее задание

Пользователь должен иметь возможность закрепить важные старые пары вопрос–ответ из доступной истории. Реализуйте `PinnedContextAssembler`: закреплённые пары получают приоритет перед свежим хвостом, но общий бюджет остаётся обязательным.

Готовый чат и базовая сборка контекста предоставлены. Правила выбора описаны в [задании](homework/README.md); результат и ограничения зафиксируйте в [SUBMISSION.md](homework/SUBMISSION.md).

## Проверка

Нужны JDK 25 и Node.js 24. Каждый блок выполняется независимо из папки `lesson-2.1`.

Лекционный пример:

```bash
cd lecture
./mvnw test
npm ci
npm test
```

Домашнее задание:

```bash
cd homework
./mvnw -Dtest='*Test,!*HomeworkAcceptanceTest' test
./mvnw -Dtest=PinnedContextHomeworkAcceptanceTest test
npm ci
npm test
```

Первая Java-команда проверяет готовую основу, вторая — новое поведение после реализации ДЗ. Настройка модели и запуск сравнения описаны в [лекции](lecture/README.md).
