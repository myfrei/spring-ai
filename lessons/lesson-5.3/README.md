Агент читает файл, предлагает точную замену и ждёт отдельного решения человека. Режимы ASK/PLAN/EDIT, same-run receipts, hash версии, TTL и одноразовые решения проверяет Java-код. Файл меняется только после ручного APPROVE. Текст модели не является разрешением.

ДЗ развивает проект: проверяет согласованность нескольких предложений до их дальнейшего рассмотрения. Лекционный write-tool и HTTP-адаптеры уже предоставлены; студент реализует отдельную policy. Preflight не пишет файлы и не является multi-file transaction.
