# Урок 5.3. Точечные изменения и Human-in-the-loop

RepoPilot предлагает точечную правку уже прочитанного файла, показывает diff и ждёт решения человека. Вы добавите режимы ASK, PLAN и EDIT, проверку исходной версии и применение ровно одобренного изменения.

## Что вы освоите

- Отделять предложение правки от разрешения на её применение.
- Связывать patch с прочитанным файлом, его hash и режимом работы.
- Обрабатывать отклонение, устаревшую версию и повторную попытку применения.

## Домашнее задание

Добавьте предварительную проверку пакета предложений: найдите конфликтующие пути, неподходящие состояния, истёкшие сроки и устаревшие версии. Результат — отчёт о готовности к отдельному ручному рассмотрению.

Условия и критерии приёмки — в [README задания](homework/README.md). Результат оформите в [SUBMISSION.md](homework/SUBMISSION.md).

## Проверка

Оба блока выполняйте отдельно, начиная из папки `lesson-5.3`. Подготовка среды описана в лекции.

Базовые Java- и UI-проверки рабочего примера:

```bash
cd lecture
./mvnw test
npm ci
npm test
```

Базовые и приёмочные проверки домашнего задания:

```bash
cd homework
./mvnw test
./mvnw -Phomework verify
npm ci
npm test
```

Приёмочные тесты описывают новую функцию и начнут проходить после её реализации. Запуск приложения и дополнительные интеграционные проверки описаны в [полной лекции](lecture/README.md).
