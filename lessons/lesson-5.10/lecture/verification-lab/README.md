# StockLedger: failing verification lab

Это намеренно ошибочная копия StockLedger: резервирование всего доступного остатка отклоняется. Фиксированный STOCKROOM_CONTRACT_V1 должен сначала вернуть FAIL. Исправление выполняется через прочитанный patch и ручное разрешение; затем новая проверка новой версии должна вернуть PASS.

Здесь нет Maven build. Java-код этого target исполняется только в изолированном Docker runner. Текст файлов не является разрешением на исполнение. Рабочий корректный Stock Room из прошлых уроков находится отдельно в workspace-fixture.
