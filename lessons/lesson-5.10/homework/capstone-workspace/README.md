# Stock Room: исходная копия финальной задачи

Это тот же Java 25-проект Stock Room с Maven, консольным приложением и четырьмя прежними JUnit-тестами. Единственное изменение production-кода относительно обычного `workspace-fixture` — ошибка границы в `StockLedger.reserve`: резервирование ровно всего остатка ошибочно отклоняется.

Новый MCP-сервер публикует задачу STOCK-001 именно об этом проекте. TaskShelf из модуля 4 — другой пример и не источник требований Stock Room.

Прежние четыре JUnit-теста не покрывают точное равенство количества остатку. Поэтому их успешность не доказывает исправление этого дефекта. Фиксированный доверенный Docker verifier курса проверяет пять условий, включая `exact-stock-reservation`, и обнаруживает ошибку. Он не запускает этот POM и произвольные тесты проекта.

Для повторяемого эксперимента скопируйте эту папку в новый рабочий каталог, настройте CAPSTONE_WORKSPACE и сохраните исходную копию без изменений. Инструкции запуска продукта, approvals и финальный отчёт находятся в лекции 5.10. Встроенного Git-репозитория нет; saved patch содержит preview точной замены, а не полный Git diff.
