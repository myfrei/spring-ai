К собственному runtime добавляются listFiles/searchText/readFile/gitStatus/gitDiff для заранее настроенного workspace. Модель получает ограниченные операции чтения; Java-код проверяет пути, symlinks, UTF-8, размеры и результаты Git. Учебный Java 25-проект даёт воспроизводимый объект исследования. Chat/RAG/MCP из предыдущих уроков сохраняются; нового UI нет.

Каждое чтение создаёт receipt конкретного run: путь, hash файла и реально прочитанные строки. Поиск и имя файла не равны прочитанному содержимому. Receipt не разрешает запись и не доказывает, что модель правильно поняла код.

В homework инфраструктура готова. Новая EvidencePolicy сопоставляет claims с receipts того же run, текущим hash и покрытием строк без дыр. Это самостоятельное приращение: студент не повторяет файловые tools, Git ProcessBuilder или агентский цикл. Изменение файлов и Skills относятся к следующим урокам.
