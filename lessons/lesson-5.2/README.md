# Урок 5.2. Навигация по коду и Git-контекст

RepoPilot начинает исследовать учебный репозиторий: находить файлы, читать код и смотреть Git status и diff. Вместе с прочитанными строками приложение сохраняет путь и hash версии файла — основу для проверяемых ссылок в ответе.

## Что вы освоите

- Добавлять инструменты навигации, поиска и чтения файлов.
- Ограничивать workspace, пути, объём чтения и результаты Git-команд.
- Фиксировать, какие строки и какую версию файла получил конкретный запуск.

## Домашнее задание

Добавьте проверку ссылок ответа: подтверждайте, что указанные строки действительно прочитаны в том же запуске и относятся к текущей версии файла. Учтите пересекающиеся диапазоны и пропуски между ними.

Условия и критерии приёмки — в [README задания](homework/README.md). Результат оформите в [SUBMISSION.md](homework/SUBMISSION.md).

## Проверка

Оба блока выполняйте отдельно, начиная из папки `lesson-5.2`. Подготовка среды описана в лекции.

Базовые Java- и UI-проверки рабочего примера:

```bash
cd lecture
./mvnw test
npm ci
npm test
```

Базовые и приёмочные проверки домашнего задания:

```bash
cd homework
./mvnw test
./mvnw -Phomework verify
npm ci
npm test
```

Приёмочные тесты описывают новую функцию и начнут проходить после её реализации. Запуск приложения и дополнительные интеграционные проверки описаны в [полной лекции](lecture/README.md).
