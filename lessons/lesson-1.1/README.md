# Урок 1.1. От пустого проекта до локальной LLM

Создаём первую версию RepoPilot: Java-приложение принимает вопрос по HTTP и получает ответ от локальной модели через Spring AI. Начнём с пустого проекта и проверим весь путь от запроса пользователя до JSON-ответа.

## Что вы освоите

- Соберёте приложение на Java 25, Spring Boot и Spring AI с Maven Wrapper.
- Подключите Ollama и разберётесь в ролях `ChatClient` и `ChatModel`.
- Реализуете `POST /api/chat`, валидацию вопроса и обработку недоступной модели.

## Домашнее задание

Добавьте отдельный сценарий объяснения Java-темы: краткий режим BRIEF и пошаговый GUIDED. Базовый чат уже готов; вам предстоит сформировать разные инструкции, сохранив вопрос пользователя отдельным сообщением.

Сравните ответы обоих режимов на настоящей модели и заполните [SUBMISSION.md](homework/SUBMISSION.md). Условия и границы реализации — в [README задания](homework/README.md).

## Проверка

Нужен JDK 25. Каждый блок ниже выполняется независимо из папки `lesson-1.1`.

Лекционный пример:

```bash
cd lecture
./mvnw test
```

Домашнее задание:

```bash
cd homework
./mvnw -Dtest=ExplanationAcceptanceTest,ExplanationHttpAcceptanceTest test
./mvnw test
```

Приёмочные тесты новой функции должны пройти после реализации ДЗ. Автоматические проверки не требуют запущенной модели; настройка Ollama и первый реальный запрос описаны в [лекции](lecture/README.md).
