# Урок 1.1. От пустого проекта до локальной LLM

- [Полная лекция и рабочий проект](lecture/README.md).
- [Домашнее задание и каркас реализации](homework/README.md).
- [Отчёт о проверке материалов](VERIFICATION.md).
- [Программа курса](../../docs/Course-Program.md).

```text
lesson-1.1/
  lecture/       # Полный пример, лекция, 21 unit/MVC-проверка и 4 HTTP-интеграционные проверки
  homework/      # Готовый базовый чат + новая политика BRIEF/GUIDED, 33 проверки
```

В каждой папке собственные `pom.xml`, Maven Wrapper, `src/main` и `src/test`. Открывайте их как отдельные Maven-проекты. Одинаковые Java package names не мешают независимой сборке.

Основной стек: Java 25, Spring Boot 4.1.2, Spring AI 2.0.2, Maven 3.9.11 и Ollama. Модель примера — `qwen2.5:3b`, её можно заменить конфигурацией.

Из `lecture` запускайте `./mvnw test` и `./mvnw spring-boot:run`. В `homework` базовый чат полностью готов; самостоятельное задание — два режима объяснений Java-кода в новом `/api/explanations`. Заполните один TODO в `ExplanationPolicy`, затем добейтесь зелёного результата всех 33 Java-проверок. Базовые 25 проверок проходят сразу, новые проверки политики выявляют незавершённую реализацию. Сборка без тестов проверяет только компиляцию и не означает выполненное ДЗ.
