# Урок 2.3. Первый RAG с pgvector

Подключим подготовленные embeddings к постоянному поисковому индексу PostgreSQL/pgvector. RepoPilot будет находить подходящие фрагменты документации, передавать их модели в пределах бюджета и показывать ссылки на источники.

## Что вы освоите

- Сохраните векторы в pgvector и выполните поиск с ограничениями по корпусу и профилю индекса.
- Соберёте RAG-контекст из найденных фрагментов с учётом бюджета.
- Покажете ссылки на чанки, фактически переданные модели.

## Домашнее задание

Несколько похожих фрагментов одного файла могут вытеснить другие полезные источники. Реализуйте `EvidenceSelector`: удаляйте повторы и перекрытия, ограничивайте число фрагментов одного документа и последовательно нумеруйте выбранные источники.

Поиск и генерация уже предоставлены. Полный контракт выбора — в [задании](homework/README.md); наблюдения и результаты внесите в [SUBMISSION.md](homework/SUBMISSION.md).

## Проверка

Нужны JDK 25 и Node.js 24. Каждый блок выполняется независимо из папки `lesson-2.3`.

Лекционный пример:

```bash
cd lecture
./mvnw test
npm ci
npm test
```

Домашнее задание:

```bash
cd homework
./mvnw -Dtest='*Test,!*HomeworkAcceptanceTest' test
./mvnw -Dtest=EvidenceSelectionHomeworkAcceptanceTest test
npm ci
npm test
```

Новые приёмочные проверки должны пройти после реализации выбора источников. Для SQL-интеграции и запуска RAG нужны Docker, база и модели: выполните [подготовку и проверки из лекции](lecture/README.md).
