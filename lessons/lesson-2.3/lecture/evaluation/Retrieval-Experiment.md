## Сравнение

Прогоните topK=2/4/8 и threshold=0/0.35/0.7 на неизменных данных. Все значения — точки эксперимента, не рекомендуемые универсальные пороги. Зафиксируйте число возвращённых и переданных в prompt чанков, оценку входа, omittedChunks, время retrieval и полный ответ. Для времени ответа и TTFT используйте отдельный замер; этот UI не показывает точные метрики.

Для вопросов с ответом посчитайте долю вопросов, где найден хотя бы один заранее размеченный достаточный набор свидетельств. Уточните правило для многодокументных вопросов; не называйте эту долю recall всех релевантных чанков без полной разметки.
