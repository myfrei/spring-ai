# Урок 1.2. Web UI и состояния чата

У RepoPilot появляется браузерный интерфейс: можно написать вопрос, дождаться ответа и увидеть понятную ошибку при недоступности модели. Страницу обслуживает то же Spring Boot приложение — отдельная frontend-сборка не нужна.

## Что вы освоите

- Свяжете HTML-форму с Java API через `fetch`.
- Покажете состояния ожидания, успешного ответа и ошибки без потери вопроса.
- Разделите HTTP-вызов, управление состоянием и отображение, чтобы проверять UI автоматически.

## Домашнее задание

На отдельной странице `/draft.html` вопрос должен сохраняться после перезагрузки. Реализуйте хранилище черновика в `localStorage`: восстанавливайте текст, переживайте отказ хранилища и очищайте только успешно отправленную версию.

Backend и обычный чат уже предоставлены. Проверьте сценарии перезагрузки и ошибки, затем заполните [SUBMISSION.md](homework/SUBMISSION.md) по [условиям задания](homework/README.md).

## Проверка

Нужны JDK 25 и Node.js 24. Каждый блок выполняется независимо из папки `lesson-1.2`.

Лекционный пример:

```bash
cd lecture
./mvnw test
npm ci
npm test
```

Домашнее задание:

```bash
cd homework
./mvnw test
npm ci
node --test src/test/js/draft-acceptance.test.mjs
npm test
```

Приёмочные тесты черновика должны пройти после реализации ДЗ. Запуск приложения и подключение локальной модели описаны в [лекции](lecture/README.md).
