Оба проекта самостоятельные: Java 25 / Spring Boot 4.1.2 / Spring AI 2.0.2, собственный Maven Wrapper. Статические HTML/CSS/JS обслуживаются Spring Boot. Node.js 24 и jsdom нужны только для проверок JavaScript.

Из папки `lecture`:

```bash
./mvnw package
npm ci
npm test
./mvnw spring-boot:run
```

При работающем Ollama страница доступна по `http://127.0.0.1:8080/`. Настройка модели — по уроку 1.1. Без Ollama проходят автоматические проверки; настоящую генерацию проверяют отдельно.

В `lecture` проходят 29 Java-проверок и 24 проверки JavaScript. В `homework` базовые backend и UI полностью готовы. Самостоятельное задание — сохраняемый между перезагрузками черновик на `/draft.html`: versioned localStorage, безопасный отказ и очистка только отправленного текста. Реализуется только `draft-store.js`. Базовые 29 Java и 24 JS проходят; 6 новых JS-проверок сначала красные. Дополнительно проходит regression-проверка отказа самого getter localStorage. Эталон проходит 29 Java + 31 JS.

Скриншот показывает тестовый ответ локальной HTTP-заглушки, а не результат настоящей LLM. Качество модели этим снимком не подтверждается.
