## Каркас homework — новая самостоятельная задача

Полные лекционные backend и UI предоставлены готовыми. Студент реализует versioned draft storage для отдельной `/draft.html`: восстановление после reload, безопасный отказ localStorage и compare-and-clear после успешной отправки. Единственный незавершённый модуль — `draft-store.js`.

Повторный offline-прогон на JDK 25 и Node 24:

- Java: **29 из 29 зелёные**.
- JavaScript: **31 проверка**; базовые **24** и новая regression-проверка предоставленного binding зелёные, **6 acceptance ожидаемо красные** на явных TODO.
- Отключённых и пропущенных тестов нет; основной и тестовый код компилируется.

В отдельной временной копии реализован только `draft-store.js`, тестовые исходники не менялись: **29 Java + 31 JS зелёные**. Эталон в homework не включён. Новая страница проверена DOM-тестами с transport-заглушкой; отдельный визуальный browser-прогон этого расширения не заявляется. localStorage compare-and-clear имеет документированную границу best effort между вкладками. Доступ к самому getter localStorage перенесён внутрь try/catch: отказ браузера до getItem не ломает чат. Этот случай отдельно подтверждён `draft-binding.test.mjs` и в каркасе, и в эталоне.

## Браузерная проверка

Упакованный lecture запущен локально с HTTP-заглушкой Ollama. В браузере проверены:

1. Начальная страница, подписи и доступность поля.
2. Отправка вопроса, видимое ожидание и disabled формы.
3. Появление ответа и кода, очистка поля и счётчика.
4. Отказ provider → HTTP 503 → ошибка в UI, сохранённый вопрос, доступная форма.
5. Следующий успешный запрос после ошибки.
6. HTML-подобный ответ `<img ...>` отображается текстом; внутри ленты не создаётся ни img, ни script.

В консоли проверенной вкладки JavaScript-ошибок не обнаружено. [Снимок успешного сценария](Preview.jpg) содержит заранее заданный тестовый ответ. Временный стенд и вкладка после проверки закрыты.

## Границы результата

Настоящий Ollama на машине подготовки не запущен, веса не скачивались. Не проверены качество и скорость генерации выбранной модели. Прогон с реальной LLM предусмотрен в лекции и отчёте студента.

jsdom проверяет DOM и события, но не геометрию CSS; браузерный прогон выполнен на desktop. Команды других ОС описаны как инструкции, фактическая проверка — на macOS aarch64.

## Повторить проверки

Из соответствующей папки lecture или homework, с выбранными JDK 25 и Node 24:

```bash
./mvnw package
npm ci
npm test
```

Для запуска с настоящим Ollama:

```bash
./mvnw spring-boot:run
```

Открыть `http://127.0.0.1:8080/`. Результаты домашней реализации записываются в [SUBMISSION.md](homework/SUBMISSION.md).
