Добавляем immutable PlanSpec, состояния шагов, зависимости и серверную проверку receipts. Сводка обновляется перед каждым вызовом модели. Ответ не попадает в завершённую историю, пока обязательные критерии не подтверждены актуальными чтениями.

ДЗ развивает готовую базу: PlanFrontierPolicy выбирает следующие доступные шаги под лимит количества и бюджет строк. Preview не исполняет tools и не повторяет реализацию plan runtime.
