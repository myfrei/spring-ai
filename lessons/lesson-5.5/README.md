# Урок 5.5. План и проверяемый прогресс

RepoPilot хранит план отдельно от свободного ответа модели: у шагов появляются состояния, зависимости и критерии завершения. Прогресс подтверждается актуальными чтениями кода, а обязательные незавершённые шаги остаются видимыми.

## Что вы освоите

- Описывать план со статусами, зависимостями и обязательными шагами.
- Обновлять сводку плана перед следующим обращением к модели.
- Связывать завершение шага с серверными свидетельствами чтения и версией файла.

## Домашнее задание

Добавьте выбор следующих доступных шагов: учитывайте зависимости, активную работу, обязательных потомков и бюджет чтения. Предпросмотр формирует очередь задач с объяснением, что не поместилось или пока заблокировано.

Условия и критерии приёмки — в [README задания](homework/README.md). Результат оформите в [SUBMISSION.md](homework/SUBMISSION.md).

## Проверка

Оба блока выполняйте отдельно, начиная из папки `lesson-5.5`. Подготовка среды описана в лекции.

Базовые Java- и UI-проверки рабочего примера:

```bash
cd lecture
./mvnw test
npm ci
npm test
```

Базовые и приёмочные проверки домашнего задания:

```bash
cd homework
./mvnw test
./mvnw -Phomework verify
npm ci
npm test
```

Приёмочные тесты описывают новую функцию и начнут проходить после её реализации. Запуск приложения и дополнительные интеграционные проверки описаны в [полной лекции](lecture/README.md).
